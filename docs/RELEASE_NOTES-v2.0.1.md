# Offer猎手 v2.0.1

猎聘单平台桌面投递助手，基于 [loks666/get_jobs](https://github.com/loks666/get_jobs) 二次开发。

## 本次更新

- 城市选项扩展到 374 个（含港澳、地级市和自治州），支持搜索、多选和“全国 / 不限”。
- 投递时按“关键词 × 城市”依次搜索，每个城市单独校验城市名、公司规模、薪资、发布时间和 HR 活跃度。
- 主界面视觉重做：奶油晨光画布、浅色侧栏、深青文字与日出金点缀。
- 修复投递分析宽表把页面撑宽的问题。
- 修复分页上限在城市/关键词之间复用的问题。
- 启动时自动同步城市选项，旧数据库无需手动迁移。

## 安装 / 运行要求

- Windows 10 / 11 x64
- Java 21（`JAVA_HOME` 或 PATH）
- Node.js 20+（浏览器驱动需要，PATH）

## Release 资产

- `OfferHunter-2.0.1-portable.exe`：单文件便携版。
- `OfferHunter-2.0.1-win-x64.zip`：解压后运行 `Offer猎手.exe`。
- `SHA256SUMS.txt`：校验文件。
