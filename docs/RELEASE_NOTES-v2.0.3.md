# Offer猎手 v2.0.3

猎聘单平台桌面投递助手，基于 [loks666/get_jobs](https://github.com/loks666/get_jobs) 二次开发。

## 本次更新

- 修复符合条件的岗位在点击「聊一聊」时 30 秒超时、被漏投的问题：
  - 点击前重新悬停并重新定位按钮，解决抓取详情页后悬停态丢失、按钮被收起的情况。
  - 每张卡片处理前关闭「我的沟通」右侧栏，避免它挡住卡片上的按钮。
  - 点击超时从 30 秒缩短到 10 秒，点不到时快速跳过，不再长时间卡住。
- 其余功能与 v2.0.2 一致。

## 升级说明

- 直接替换程序即可，投递记录和登录态保存在 `%APPDATA%\GetJobs Liepin`，升级不会丢失。
- 本版本只修复点击流程，不改变任何筛选条件。

## 安装 / 运行要求

- Windows 10 / 11 x64
- Java 21（`JAVA_HOME` 或 PATH）
- Node.js 20+（浏览器驱动需要，PATH）

## Release 资产

- `OfferHunter-2.0.3-portable.exe`：单文件便携版。
- `OfferHunter-2.0.3-win-x64.zip`：解压后运行 `Offer猎手.exe`。
- `SHA256SUMS.txt`：校验文件。
